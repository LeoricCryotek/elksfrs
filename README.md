# Elks FRS

Odoo 19 financial reporting, chart of accounts, budgeting, cash management and
QuickBooks Online expense synchronization for Elks lodges.

QuickBooks functionality is built into FRS version **19.0.3.0.1**. The installation
and upgrade automatically adopt data from the former separate connector without
reimporting or reposting transactions. Approval automation uses the optional
`elkspurchase` application.

See [QuickBooks setup and migration](docs/qbo_install_upgrade.md) for installation,
upgrade commands, data-preservation details, supported scope and test commands.
